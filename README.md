# Elevate School Website

## Project Overview
This project is a responsive website for a fictional school named **Elevate**. The website includes essential pages to showcase the school's offerings and engage with its audience. The pages include:

- **Homepage**: Features a navigation menu, a hero section with a banner, key highlights, and a welcoming message.
- **About Us**: Details the school's history, mission, vision, values, and staff/team section.
- **Courses**: Lists courses with descriptions, durations, and a card layout for each course.
- **Testimonials**: Displays student/alumni testimonials with photos and names in a quote or carousel format.
- **Contact**: Includes a contact form, Google Map embed, and school contact details with social media links.

The content for this project is sourced from [era92elevate.org](https://era92elevate.org).

## Project Requirements
- **Homepage**:
  - Header with school name/logo and navigation menu (Home, About Us, Courses, Testimonials, Contact).
  - Hero section with a banner image or video and a message: "Welcome to Elevate School – Empowering the Leaders of Tomorrow."
  - Key highlights showcasing "Experienced Faculty," "Innovative Courses," and "Community-Oriented."
- **About Us Page**:
  - School history, mission, vision, and values with images/icons representing core values.
  - Staff/team section with names, photos, and positions.
- **Courses Page**:
  - List of courses with brief descriptions, durations, and a card layout.
  - Each course card includes an image, title, description, and a "Learn More" link/modal.
- **Testimonials Page**:
  - Student/alumni testimonials with photos, names, and quotes (in a quote section or carousel).
- **Contact Page**:
  - Contact form with fields for Name, Email, Message, and a Submit button.
  - Google Map embed showing the school's location.
  - Contact details (phone, email) and social media links.
